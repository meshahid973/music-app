## Changes in the accompanying PR

- Native folder scans now collect unreadable/deeply nested directory paths instead of swallowing the failure without returning it.
- Native folder import/rescan, dropped-folder import, and saved cover-folder recovery display a warning when only part of a folder could be scanned. Accessible files are still imported.
- A regression test verifies that accessible audio and cover files are retained when a nested directory is unreadable.
- Windows CI now attempts a silent per-user install of the generated NSIS setup.exe, starts the installed executable, and verifies that it stays running for a short startup window.
- README now distinguishes the browser and Windows desktop versions and documents the limitation that embedded metadata parsing currently reads ID3 tags.
